# Tk_Tk  Portfolio

Portfolio personnel one page de **Kadjo Kadjo Joël Timothée** (alias **Tk_Tk**), étudiant en 2e année de Licence Génie Logiciel à l'**IIT – Institut Ivoirien de Technologie** (Côte d'Ivoire).

Le site présente mon parcours, mes compétences et mes projets, et permet de me contacter directement.

**Voir le site en ligne : [kadjotimothee00-pixel.github.io/Mon-portfolio](https://kadjotimothee00-pixel.github.io/Mon-portfolio/)**

## Aperçu

Le site contient une seule page, découpée en sections :

| Section | Contenu |
|---|---|
| **Accueil** | Présentation, photo, rôles et accès rapide aux projets et au CV |
| **01- À propos** | Qui je suis, ma formation, ce que je fais |
| **02- Skills & Stack** | Langages, bases de données, outils de conception et de développement |
| **03- Projets** | ExploreCI, Gestion de bibliothèque, Web scraping Jumia CI & Amazon.fr |
| **04- Contact** | Mes comptes et un formulaire de contact |

## Technologies

- **HTML5 / CSS3 / JavaScript** (sans framework JS, sans jQuery)
- **Bootstrap 5.3** (grille responsive, barre de navigation, menu burger, scrollspy), chargé par CDN
- **Google Fonts** : Archivo, Inter, JetBrains Mono
- **Formspree** pour l'envoi du formulaire de contact





## Lancer le site en local

1. Cloner le dépôt ou télécharger le dossier.
2. Ouvrir `index.html` dans un navigateur (double-clic).
